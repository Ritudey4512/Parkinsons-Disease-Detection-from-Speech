ABOUT THE PROJECT

How the system works

The current model is trained on already-extracted Parkinson's speech features. A prediction is produced from the 22 numerical measurements below.

01

Voice Features

Measurements such as fundamental frequency, jitter, shimmer, HNR, RPDE and PPE.

02

Preprocessing

The same Min-Max scaling pipeline used during training is applied to new input.

03

KNN Prediction

The trained K-Nearest Neighbors model compares the input with learned patterns.
